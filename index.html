DESIGN & ANALYSIS OF ALGORITHMS

How the Algorithm Works

⚙

Greedy Interval Partitioning + Min Heap

Each flight is treated as a time interval [arrival, departure]. Airport gates are limited resources. The algorithm assigns the earliest available gate to each flight while processing flights in chronological order.

Algorithm Steps

01

Enter Flights

Store flight ID, airline, arrival, departure, passenger count and route.

→
02

Sort by Arrival

Sort all flights in increasing order of arrival time.

→
03

Check Gates

Look at gates currently occupied by previous flights.

→
04

Release Gates

Release every gate whose previous flight has already departed.

→
05

Assign Gate

Select the smallest available gate using the Min Heap.

→
06

Detect Conflict

If no gate is available, mark the flight as a conflict.

Priority Queue / Min Heap Structure

✓

Available Gates Min Heap

Stores currently free gates

G1 G2 G3 G4

The smallest gate number is selected whenever a new flight needs a gate.

◷

Busy Gates Min Heap

Stores occupied gates by departure time

09:30 G1
10:00 G2
11:00 G3

The earliest departing flight is always available at the top of the heap.

CORE ALLOCATION RULE

Previous Departure ≤ Current Arrival

If a previous flight has departed before or exactly when the next flight arrives, its gate can be reused.

Pseudocode 

SORT flights by arrival time

CREATE AvailableGates Min Heap
CREATE BusyGates Min Heap

FOR each flight:

    WHILE BusyGates is not empty
          AND earliest departure <= flight arrival:

        release gate
        move gate to AvailableGates

    IF AvailableGates is not empty:

        gate = smallest available gate

        assign gate to flight

        insert
        (flight departure, gate)
        into BusyGates

    ELSE:

        mark flight as CONFLICT

END FOR

Complexity Analysis

TIME COMPLEXITY O(n log n)

Sorting takes O(n log n), and heap operations take O(log k).

SPACE COMPLEXITY O(n + k)

Stores flight information and gate priority queues.

STRATEGY GREEDY

Assign the earliest available gate to every flight.
